# HireHive - Symfony Frontend Migration

Bienvenue dans le projet HireHive migré de JavaFX vers Symfony avec Twig et Webpack Encore.

## 🎯 Project Overview

Ce projet est une migration complète d'une application JavaFX vers Symfony avec:
- ✅ **Twig templates** pour la génération HTML
- ✅ **Webpack Encore** pour la gestion des assets
- ✅ **CSS converties** du JavaFX vers le web standard
- ✅ **Chart.js** pour les graphiques
- ✅ **Stimulus JS** pour l'interactivité
- ✅ **Dark mode** design theme
- ✅ **Responsive** layouts (mobile, tablet, desktop)

## 🚀 Installation

### Prerequisites
- PHP 8.1+
- Node.js 16+
- Composer
- Git (optional)

### Setup (3 steps)

**1. Install dependencies**
```bash
composer install
npm install
```

**2. Copy JavaFX assets**
```powershell
.\port-to-symfony.ps1 -JavaFxSourcePath "C:\path\to\javafx\project"
```

Or manually:
```bash
cp -R "C:\javafx\src\main\resources\assets\*" public/assets
cp "C:\javafx\src\main\resources\chart\chart.min.js" public/chart/
```

**3. Run development server**
```bash
# Terminal 1: Asset Watcher
npm run watch

# Terminal 2: Symfony Server
php bin/console server:run
```

Open http://localhost:8000 🎉

## 🛠 Common Tasks

### Edit Styles
Edit `assets/styles/javafx.css` - changes auto-reload (if npm watch is running)

### Add a New Page
1. Create `templates/mypage/index.html.twig`
2. Create controller with @Route:
```php
#[Route('/mypage', name: 'app_mypage')]
public function index(): Response {
    return $this->render('mypage/index.html.twig');
}
```
3. Visit http://localhost:8000/mypage

### Pass Data to Template
In Controller:
```php
return $this->render('mypage/index.html.twig', [
    'myVariable' => 'value',
    'items' => [1, 2, 3]
]);
```

In Twig:
```twig
<p>{{ myVariable }}</p>
{% for item in items %}
  <li>{{ item }}</li>
{% endfor %}
```

### Build for Production
```bash
npm run build
composer install --optimize-autoloader --no-dev
php bin/console cache:clear --env=prod
```

## 📖 Code Examples

### Render a Dashboard with Data
```php
// src/Controller/DashboardController.php
#[Route('/dashboard', name: 'app_dashboard')]
public function index(): Response {
    return $this->render('dashboard/admin_dashboard.html.twig', [
        'totalClaims' => 125,
        'openClaims' => 32,
        'urgentClaims' => 8,
        'resolvedClaims' => 85,
        'chartLabels' => ['Type A', 'Type B', 'Type C'],
        'chartData' => [30, 25, 40],
    ]);
}
```

### Use Data in Twig
```twig
{% extends 'base.html.twig' %}

{% block title %}Mon Dashboard{% endblock %}

{% block body %}
  <h1>Total: {{ totalClaims }}</h1>
  
  <div class="stats-grid">
    {% for label in chartLabels %}
      <div>{{ label }}: {{ chartData[loop.index0] }}</div>
    {% endfor %}
  </div>
{% endblock %}
```

## 🆘 Troubleshooting

### Port 8000 is already in use
```bash
php bin/console server:run --port=8001
```

### Assets not loading
1. Run: `npm run build`
2. Check that `public/build/` folder exists
3. Clear Symfony cache: `php bin/console cache:clear`

### Templates not updating
Clear Twig cache:
```bash
rm -rf var/cache/dev/*
```

### npm install fails
```bash
rm -rf node_modules package-lock.json
npm install
```
