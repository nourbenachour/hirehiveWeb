## 🚀 Next Steps

### 1. Install Dependencies

```bash
# Install PHP dependencies
composer install

# Install Webpack Encore Bundle (if not already done)
composer require symfony/webpack-encore-bundle

# Install npm dependencies
npm install
```

### 2. Copy JavaFX Assets

**Option A - Automated (PowerShell)**:
```powershell
.\port-to-symfony.ps1 -JavaFxSourcePath "C:\Users\user\Downloads\hirehive-integration 4\hirehive-integration\hirehive-integration"
```

**Option B - Manual**:
```bash
# Copy images
cp -R "C:\path\to\javafx\src\main\resources\assets\*" public/assets

# Copy chart
cp "C:\path\to\javafx\src\main\resources\chart\chart.min.js" public/chart/
```

### 3. The Conversion (Optional - for JavaFX CSS)

If you have existing JavaFX CSS that needs conversion:

```bash
node convert-javafx-css.js "C:\path\to\javafx\src\main\resources\resources\tn\esprit\javafx"
```

This will automatically convert properties like:
- `-fx-background-color` → `background-color`
- `-fx-padding` → `padding`
- `-fx-font-size` → `font-size`
- And 20+ more JavaFX-specific properties

### 4. Build Assets

```bash
# Development mode
npm run dev

# Watch mode (rebuilds on file changes)
npm run watch

# Production build
npm run build
```

### 5. Start Development Server

```bash
php bin/console server:run

# Navigate to http://localhost:8000
```

## 🎨 Customization Tips

### Change Color Theme
Edit `assets/styles/javafx.css`:
```css
:root {
  --primary: #60a5fa;      /* Blue accent */
  --success: #34d399;      /* Green success */
  --danger: #f87171;       /* Red danger */
  --warning: #facc15;      /* Yellow warning */
  --dark-bg: #0a0a0f;      /* Dark background */
}
```

### Add New Dashboard Cards
1. Add HTML in template
2. Use `.stat-card` class
3. Add color variant: `.stat-card-blue`, `.stat-card-yellow`, etc.

### Create Custom Pages
1. Create template in `templates/yourpage/`
2. Extend `base.html.twig`
3. Create controller that renders it
4. Add route to `routes.yaml`

## 🆘 Troubleshooting

### "Assets not found" error
- Run: `npm run build`
- Check that `public/build/` exists
- Verify paths in Twig use `asset()` helper

### CSS not applying
- Check that `assets/styles/javafx.css` exists
- Ensure `.postcssrc.json` is present
- Clear Symfony cache: `php bin/console cache:clear`

### Port already in use
```bash
php bin/console server:run --port=8001
```
